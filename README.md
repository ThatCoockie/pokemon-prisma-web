# Pokémon Prisma Edition – Web-Version

Emulator für **Pokémon Prisma Edition** im Browser, gedacht vor allem fürs iPhone.

- Läuft in Safari (und anderen modernen Browsern), auch offline.
- **Enthält kein Spiel.** Beim ersten Start wird die eigene Prisma-Spieldatei ausgewählt; sie bleibt nur auf dem Gerät.
- Startet ausschließlich signierte Pokémon-Prisma-Dateien.
- Spielstand bleibt auf dem Gerät; im Menü (☰) lässt er sich exportieren und importieren.

## Auf dem iPhone installieren
1. Seite in **Safari** öffnen.
2. **Teilen → Zum Home-Bildschirm**.
3. Die App vom Home-Bildschirm starten und einmalig die Prisma-Spieldatei aus der Dateien-App auswählen.

## Steuerung
Touch-Tasten auf dem Bildschirm, Tastatur (Pfeiltasten, X = A, Y/Z = B, Enter = Start, Shift = Select, Esc = Menü)
oder ein verbundener Controller. B gedrückt halten = rennen.

Emulator-Kern: Walnut-CGB (Peanut-GB) und minigb_apu, beide MIT-Lizenz.
